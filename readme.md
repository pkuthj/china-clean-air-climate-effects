# Clean air actions in China lead to near-neutral climate effects

This repository contains the scripts used in this study.

## Description

All scripts in this repository are provided as `.py` files.  
The OSCAR model used in this study is also written in **Python 3**.

At this stage, only part of the scripts are available in this repository.  
The full set of scripts will be organized and uploaded in a future update.

## Notes

- Script files are in Python format (`.py`).
- The analyses are based on the Python 3 version of OSCAR.
- Additional scripts and documentation will be added later.
